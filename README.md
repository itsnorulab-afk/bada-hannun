# 바다한눈

무료 공유형 낚시 PWA. iPhone Safari에서 홈 화면에 추가하여 사용합니다.

## 앱 소스 배포
`index.html`, `manifest.webmanifest`, `icon.svg`, `sw.js`, `updates.js`, `VERSION`, `.nojekyll`을 저장소 루트에 업로드합니다. `.github/workflows/deploy.yml`이 `main` 브랜치를 GitHub Pages에 배포합니다.

## 주의
서버 없는 버전은 개인 기록을 브라우저 기기에만 저장합니다. 다른 기기와 자동 동기화되지 않으므로 JSON 백업을 꼭 보관하세요. 공개 웹사이트이므로 링크를 아는 누구나 앱을 열 수 있습니다.
